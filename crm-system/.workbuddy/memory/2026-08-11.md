## 完成的主要工作

### 1. 全面代码审查与问题修复

完成了对 LalaCRM 项目的全面代码审查，共发现并修复了 14 个问题：

#### 🔴 高严重度问题（3个）

1. **PrismaClient 单例化**
   - 问题：项目中存在 44 个 `new PrismaClient()` 实例，浪费连接资源
   - 修复：创建 `backend/src/lib/prisma.ts` 单例模块，所有文件统一导入使用
   - 影响：减少数据库连接数，提升性能

2. **WebSocket 心跳定时器泄漏**
   - 问题：WebSocket 心跳检测定时器在进程关闭时未清理
   - 修复：添加 `cleanupWebSocket()` 函数，在 `gracefulShutdown()` 中调用
   - 影响：避免内存泄漏和定时器堆积

3. **项目付款完结过滤优化**
   - 问题：`fullyPaid=true` 时先查询全部项目再内存过滤，数据量大时性能差
   - 修复：使用原生 SQL 在数据库层面完成过滤和分页
   - 影响：大数据量下性能显著提升

#### 🟡 中严重度问题（5个）

4. **合同列表数据权限**
   - 问题：合同列表缺少数据权限过滤，任何人都能看到所有合同
   - 修复：添加 `getContractDataScope()` 函数，非管理员只能看到自己创建的或项目团队成员的合同
   - 影响：数据安全

5. **管理员判断逻辑统一**
   - 问题：登录时使用 `user.role === 'ADMIN'`，权限检查使用 `UserRole` 表，判断不一致
   - 修复：统一使用 `isAdmin(userId)` 函数判断
   - 影响：避免权限判断混乱

6. **新角色默认数据范围**
   - 问题：创建角色时默认 `dataScope='ALL'`，过于宽松
   - 修复：改为默认 `SELF`
   - 影响：更安全的默认配置

7. **Blob 请求错误信息丢失**
   - 问题：`responseType: 'blob'` 时，错误响应也是 blob，无法直接读取错误信息
   - 修复：拦截器中特殊处理 blob 错误响应，尝试解析为 JSON
   - 影响：改善用户体验，能看到具体错误信息

8. **数据库备份同步 IO**
   - 问题：使用 `writeFileSync/readFileSync` 阻塞主线程
   - 修复：改为 `fs.promises` 异步读写
   - 影响：避免阻塞 Node.js 事件循环

## 技术细节

### PrismaClient 单例化实现

创建 `backend/src/lib/prisma.ts`：
```typescript
import { PrismaClient } from '@prisma/client'

const globalForPrisma = globalThis as unknown as {
  prisma: PrismaClient | undefined
}

export const prisma = globalForPrisma.prisma ?? new PrismaClient()

if (process.env.NODE_ENV !== 'production') {
  globalForPrisma.prisma = prisma
}
```

所有路由文件统一导入：
```typescript
import prisma from '../lib/prisma'
```

### WebSocket 清理实现

```typescript
export function cleanupWebSocket() {
  if (heartbeatTimer) {
    clearInterval(heartbeatTimer)
    heartbeatTimer = null
  }
  wss?.close()
}
```

在 `gracefulShutdown()` 中调用：
```typescript
cleanupWebSocket()
```

### 项目付款完结 SQL 优化

使用原生 SQL 在数据库层面完成过滤：
```sql
SELECT p.id FROM "Project" p
WHERE ...
AND EXISTS (
  SELECT 1 FROM "Contract" c 
  WHERE c."projectId" = p.id AND c."deletedAt" IS NULL
)
AND (
  SELECT COALESCE(SUM(CAST(c.amount AS DECIMAL)), 0)
  FROM "Contract" c 
  WHERE c."projectId" = p.id AND c."deletedAt" IS NULL
) <= (
  SELECT COALESCE(SUM(CAST(c.amount AS DECIMAL)), 0)
  FROM "Contract" c
  JOIN "ContractReceipt" cr ON cr."contractId" = c.id
  WHERE c."projectId" = p.id AND c."deletedAt" IS NULL AND cr."deletedAt" IS NULL
)
```
