## 群晖部署 ARM64 镜像打包

为 DS223j（ARM64）构建三个镜像，输出到 `build/` 目录：
- `backend.tar` (727M) — crm-backend:arm64（含 LibreOffice）
- `frontend.tar` (26M) — crm-frontend:arm64（nginx + vite build）
- `postgres.tar` (108M) — postgres:15-alpine-arm64

镜像 tag 与 `docker-compose.synology.yml` 完全对齐。

### 构建要点
- 用 `docker buildx` + `synology-builder`（docker-container driver）跨平台构建 linux/arm64
- 后端/前端直接用各自 Dockerfile 构建，`--output type=docker,dest=xxx.tar` 导出
- **PostgreSQL 导出踩坑**：`docker pull --platform linux/arm64` 后 `docker save` 会报 `content digest not found`（Docker Desktop WSL2 跨架构 manifest list 缺失）。解决：写临时 `Dockerfile`（`FROM postgres:15-alpine`）用 buildx `--platform linux/arm64` 导出 tar，可正常拿到完整 arm64 镜像
- 注意：原 `build-for-synology.sh` 里 tag 用的是 `:synology`，但 compose 引用的是 `:arm64`，本次构建统一用 `:arm64`
