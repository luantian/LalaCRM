## 全局统一 dayjs 中文 locale

**问题**：部分页面的日期选择器显示英文，部分是中文，不一致。

**原因**：App.tsx 已全局设置了 antd `ConfigProvider locale={zhCN}`（UI 文字中文），但 dayjs 的 locale（控制日期文本：星期、月份等）只在个别页面（Dashboard.tsx、CheckInList.tsx）单独设置，导致大多数页面日期显示英文。

**修复**：
- `frontend/src/main.tsx` - 在应用入口全局设置 `dayjs.locale('zh-cn')`
- `frontend/src/pages/Dashboard.tsx` - 移除重复的 dayjs locale 配置
- `frontend/src/pages/CheckInList.tsx` - 移除重复的 dayjs locale 配置

## 客户联系方式加密与权限配置

**问题**：客户联系方式（电话、邮箱、微信）需要加密显示，且需要可配置哪些角色可以看完整信息。

**实现**：

### 数据库
- `backend/prisma/schema.prisma` - 添加 SystemConfig 模型存储系统配置

### 后端
- `backend/src/routes/settings.ts` - 新增联系方式权限配置 API
  - GET `/api/settings/contact-info-permission` - 获取配置（返回角色 ID 列表和角色详情）
  - PUT `/api/settings/contact-info-permission` - 更新配置（仅管理员）
- `backend/src/routes/organizations.ts` - 修改脱敏逻辑
  - 从 SystemConfig 读取允许查看完整联系方式的 roleIds
  - 电话：`1234567890` → `***7890`
  - 邮箱：`zhangsan@example.com` → `z***@example.com`
  - 微信：`wx_123` → `wx***3`
  - 管理员和有权限的角色看完整信息，其他人看脱敏信息
- `backend/src/index.ts` - 注册 settings 路由

### 前端
- `frontend/src/pages/RoleManagement.tsx` - 添加"联系方式权限配置"弹窗
  - 选择哪些角色可以查看完整联系方式
  - 保存后调用 `/api/settings/contact-info-permission`
  - 联系人表格列显示脱敏或完整信息
- `frontend/src/components/OrgContactSelector.tsx` - 组件自动使用后端返回的脱敏/完整数据

### 权限控制
- 管理员：始终可以查看完整信息
- 配置的角色：可以查看完整信息
- 其他用户：只能看到脱敏信息
