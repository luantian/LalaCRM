## 修复的问题

### zip 文件上传失败
- **问题**：项目详情 Notes 信息中无法上传 zip 文件
- **原因**：后端 `upload.ts` 的 MIME 白名单只有 `application/zip`，但 Windows 浏览器发送的是 `application/x-zip-compressed`
- **修复**：在 `backend/src/middleware/upload.ts` 的 `allowedTypes` 数组中添加了 `application/x-zip-compressed` 和 `application/x-zip`
- **状态**：✅ 已修复
